### NAME

**slava** — builds things, ships them, occasionally runs a hackathon

### SYNOPSIS

```
slava [--cofound pontune] [--organize larphacks] [--hackathon N] [--no-sleep]
```

### DESCRIPTION

17, at hodan nalayeh ss, and on the exec of the school's cs / robotics club. co-founder and tech lead at [pontune](https://pontune.app). won 5 hackathons. most of the other four were forgettable, but the latest one wasn't: 2nd at communihacks with [commutr](https://github.com/kostslava/commutr).

the rest of the time it's esp32 boards, browser extensions for problems only i have, and side projects that get way out of hand.

### OPTIONS

**`--cofound`** [pontune](https://pontune.app)
&nbsp;&nbsp;&nbsp;&nbsp;hands-on lessons in code, math, physics and hardware. you write code in the browser and watch it run, and when you get stuck there's an ai tutor called clanka. the code runner underneath is [pontune-sandbox](https://github.com/kostslava/pontune-sandbox).

**`--hackathon`** [commutr](https://github.com/kostslava/commutr) &nbsp;·&nbsp; 2nd place, communihacks
&nbsp;&nbsp;&nbsp;&nbsp;walk, bike or take transit and you earn points, then spend them on rewards. muta, the mascot, takes voice commands and drives the app for you. react, hono, gemini, elevenlabs. [live demo](https://commutr-psi.vercel.app).

**`--extension`** [quizzy](https://quizzy.click)
&nbsp;&nbsp;&nbsp;&nbsp;a chrome extension that sits next to kahoot, blooket and popsauce and suggests answers. it can hint or play on its own. closed source.

**`--organize`** [larphacks](https://www.larphacks.ca)
&nbsp;&nbsp;&nbsp;&nbsp;my hackathon. 400+ applied and 150+ showed up. very little code went into it, but a lot of spreadsheets did.
